# Feature Guide: Doc↔Doc Split View

## Overview

View two documents side-by-side in EleViewer. Compare a draft against a rubric, read two chapters in parallel, or cross-reference notes while reading a PDF.

## How to Use

1. Open at least two documents
2. Click the **Split View** button in the main toolbar, or press `Ctrl+\`
3. The current document moves to the right pane
4. Open another document in the left pane, or drag tabs between panes
5. Press `Ctrl+\` again to return to single view

## Behavior

| Action | Result |
|--------|--------|
| First `Ctrl+\` | Current tab moves to right pane; left pane becomes active for new opens |
| Second `Ctrl+\` | All tabs merge back into the left pane; right pane hides |
| Open file while split | New file opens in the active (left) pane |
| Close a tab | Tab closes from its respective pane |

## Keyboard Shortcut

- `Ctrl+\` — Toggle split view on/off

## Toolbar

The Split View button appears in the main toolbar between Web Panel and Settings. It is also available in the File menu.
