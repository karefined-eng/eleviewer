# Feature Guide: Undo/Redo Toolbar

## Overview

Undo (`Ctrl+Z`) and Redo (`Ctrl+Y`) buttons are now on the main toolbar, available for all text editors (Markdown, plain text, HTML).

## How to Use

1. Open a text or Markdown document
2. Make edits to the document
3. Click **Undo** (rotate-ccw icon) or **Redo** (rotate-cw icon) on the main toolbar
4. Or use keyboard shortcuts: `Ctrl+Z` / `Ctrl+Y`

## Supported Editors

- EditorTab (plain text, Markdown, HTML)
- MarkdownViewer (simple and syntax modes)

## Toolbar Position

Undo/Redo buttons appear in the main toolbar between Save and Read Aloud. They can be reordered by dragging, like all toolbar buttons.
