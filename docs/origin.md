# EleViewer: project purpose

The repository's README describes EleViewer as an offline-first Windows study workspace that brings readings, assignments, slides, and notes together in one window. It emphasizes local files, a distraction-free study session, and integrated tools such as the split-screen web panel and Global Quick Note.

This file records only the purpose stated in the project documentation. The repository does not currently document a historical origin story, so none is inferred here.

## Product intent

- Help users keep study materials and notes together.
- Work offline and keep user files local.
- Make common study tasks accessible without adding unnecessary friction.
- Keep the app lightweight and focused.
