# EleViewer: An Offline Study Workspace for Windows

EleViewer is a free, offline-first Windows workspace for reading, organizing, and annotating study materials. It brings PDFs, Word documents, PowerPoint slides, spreadsheets, Markdown notes, and web research into one distraction-free desktop application.

## Why use an offline study workspace?

Students often switch between a PDF reader, Microsoft Office, a browser, a notes app, and a file manager during one study session. That workflow creates tab overload and makes it harder to return to the exact place where you stopped.

EleViewer keeps the session together locally. You can open a reading, write notes, search a linked study folder, and use the built-in web panel without uploading coursework to a cloud service or creating an account.

## Useful study workflows

### Read and research side by side

Open a PDF or document in EleViewer and use the split-screen web panel to look up references. This keeps the source material and research context visible in one window.

### Keep course files searchable

Link a school or project folder as a vault. EleViewer indexes the folder so that filenames and recently used materials are easier to find when preparing for an assignment or exam.

### Resume a study session

Session restore remembers open files, web pages, and reading positions. You can close the application and return to the same workspace later.

### Take a note without breaking focus

Use the global quick note shortcut (`Alt+E`) to capture an idea while working. Markdown support makes it possible to keep structured notes alongside source documents.

### Read PDFs aloud

EleViewer includes PDF text-to-speech support for listening to selected reading material when resting your eyes or reviewing notes.

## Supported file types

EleViewer supports PDF, DOCX, PPTX, XLSX, CSV, Markdown, HTML, and TXT files. It is portable, so the Windows executable can run without an administrator password or a Microsoft Office subscription.
