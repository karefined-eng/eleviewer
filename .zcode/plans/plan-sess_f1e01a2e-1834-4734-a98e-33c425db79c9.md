Implement the agreed web-panel redesign: theme-aware tab close buttons, compact unified browser header, "hit the roof" dock layout, and a toggleable main toolbar.

## 1. Theme-aware tab close buttons (fixes invisible × in dark mode)
- Add `icons/x-bright.svg` (stroke `#ffffff`) for dark mode and `icons/x-dark.svg` (stroke `#222222`) for light mode — same geometry as the current `x.svg`.
- `theme.py`:
  - Add `get_active_theme_name()` (returns `"dark"`/`"light"`, resolving `"system"` via `is_system_in_light_mode()`); refactor `get_active_palette()` to reuse it.
  - In `main_window_stylesheet()`, pick the close-icon file by active theme and rewrite the `QTabBar::close-button` block to `image: url("<absolute posix path from icons.ICONS_DIR>")` (local import inside the function — `icons.py` imports `theme` at module level, so no top-level import). Absolute path also fixes the PyInstaller relative-path fragility.
  - Delete the invalid `opacity: 0/1` and `QTabBar::tab:selected > QTabBar::close-button` rules — Qt QSS ignores both, so they currently do nothing (the × is always rendered, just black-on-dark). Keep size/padding/hover-background rules.
- Re-theming is automatic: the stylesheet regenerates at startup and in `_on_settings_saved()` (ui.py:1851). Covers main tabs, split-view tabs, and web tabs (all inherit the window QSS).

## 2. Compact unified browser header (kills the "WEB BROWSER" title row)
- `web_panel.py`: expose the nav row as `self.nav_layout` (currently a local `nav`).
- `ui.py open_web_tab()`:
  - Replace the custom title bar with an empty widget: `self._web_dock.setTitleBarWidget(QWidget())`. The dock's window title stays for the floated window. Accepted tradeoff: no drag-grip to move the dock; Pop Out button and edge-resizing remain.
  - Normalize dock button icons 26 → 24 px to match nav buttons.
  - Append to `web_panel.nav_layout`: a 1px vertical separator (`self._web_sep`), then btn_max, btn_float, btn_close — same closures/handlers as today, list renamed `self._web_dock_buttons`. Buttons get `compact_toolbar_stylesheet()` + AutoRaise to match the nav buttons.
  - `_apply_web_dock_theme()`: drop title-bar/label styling; re-style the three buttons and separator from the active palette.
  - Polish: when the panel auto-maximizes on open with zero doc tabs, sync btn_max icon/tooltip (currently it still shows the wrong state); update the Pop Out button icon/tooltip on `topLevelChanged` so it reads "Re-dock Web Panel" while floated.

## 3. "Hit the roof" layout
- In `MainWindow.__init__` (after `_build_layout()`): `self.setCorner(Qt.TopRightCorner, Qt.RightDockWidgetArea)` — the web panel docks up to the menu bar and the main toolbar stops at the document boundary. No bottom-corner change, so the status bar keeps spanning full width.

## 4. Toggleable main toolbar (View menu + persistence)
- Note: `_build_toolbar()` currently ends with an unconditional `self.toolbar.hide()` and nothing ever shows it — the toolbar is unreachable today, so this toggle is required for it to exist at all.
- `settings.py`: add `"show_toolbar": True` to `DEFAULT_SETTINGS` (default shown, matching what users see now).
- `ui.py`:
  - `_build_toolbar()`: replace the hard `hide()` with visibility from saved settings.
  - New `toggle_main_toolbar()`: flips visibility, syncs the menu action's check state, persists to settings.json, shows a status-bar message.
  - `create_menu()`: add a **View** menu (between Session and Settings) with a single checkable "Show Main Toolbar" action (`Ctrl+Alt+T`, checked state from `self.toolbar.isVisible()`).
  - `_setup_global_shortcuts()`: register `Ctrl+Alt+T` → `toggle_main_toolbar` (verified free — no conflicts with the existing shortcut set).
  - F1 shortcuts dialog: add "Toggle main toolbar — Ctrl + Alt + T" to the "View & Layout" section.
