🚀 Welcome to EleViewer

The lightweight, offline-first study workspace designed for students and power users who value speed, privacy, and zero telemetry.

⚡ The 4 Reflex Keys

Ctrl + Q
Quick Switcher
Fuzzy search your recent files and active tabs instantly.
Alt + V
Vault Explorer
Toggle your course folders and project vaults.
Ctrl + T
Web Browser Panel
Reference documentation and websites side-by-side.
F9
Read Aloud (TTS)
Turn any lecture slide, PDF, or Markdown file into audio.

📖 Supported Formats

EleViewer opens DOCX, XLSX, PDF, Markdown (.md), HTML, CSV, and plain TXT in a single unified interface with tab session restore.
